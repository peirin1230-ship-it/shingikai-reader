## 1. 一文要約

特定健診の根拠法・対象・検査項目・計画期間を9項目で並べた説明スライド。

## 2. 書いてあること

**箇条書きだけのスライドである。**図も表もグラフもない。

| 項目 | 内容 |
|---|---|
| 根拠法 | 高齢者の医療の確保に関する法律 |
| 実施主体 | 医療保険者 |
| **対象** | **40歳以上75歳未満**の被保険者・被扶養者 |
| 内容（健診） | 高血圧症、脂質異常症、糖尿病その他の**内臓脂肪の蓄積に起因する生活習慣病**に関する健康診査を実施 |
| 内容（保健指導） | 健診の結果、健康の保持に努める必要がある者に対して特定保健指導を実施 |
| 実施計画 | 医療保険者は**6年ごと**に特定健診等実施計画を策定 |
| 計画期間 | 第1期 2008年度〜2012年度／第2期 2013年度〜2017年度／<br>第3期 2018年度〜2023年度／**第4期 2024年度〜2029年度** |

### 検査項目

- **質問票**（服薬歴、喫煙歴等）
- **身体計測**（身長、体重、BMI、腹囲）
- **理学的検査**（身体診察）
- **血圧測定**
- **血液検査**
  - 脂質検査（空腹時中性脂肪、やむを得ない場合は随時中性脂肪、HDLコレステロール、LDLコレステロール）
  - 血糖検査（空腹時血糖またはHbA1c、やむを得ない場合は随時血糖）
  - 肝機能検査（AST(GOT)、ALT(GPT)、γ－GT(γ－GTP)）
- **尿検査**（尿糖、尿蛋白）

※上記項目のほか、一定の基準の下、医師が必要と認めた場合に、**心電図検査等の詳細な検査**を実施。

## 3. このスライドの役割

[p017](p017.md)の表の中心にあった「特定健診」を取り出して説明する1枚。
[p018](p018.md)が「なぜ保険者が予防をやるか」、
本スライドが「何をやるか」、[p020](p020.md)が「どこまでできているか」である。

【解釈】4枚のなかで**唯一、制度の内容を具体的に列挙している。**
検査項目まで書かれているのは、
第4期計画の期間（2024〜2029年度）が現在進行中であることによると考えられる【推測】。

## 4. 背景

### 4-1. 制度背景

特定健診は、老人保健法に基づく基本健康診査を組み替えて
**平成20年（2008年）4月**に始まった。
このとき同時に後期高齢者医療制度も始まっている（→ [p076](p076.md)）。

実施主体が市町村から**医療保険者**に移ったことがこの改正の要点である。
保険者は自らの加入者（被扶養者を含む）に対して健診を行う義務を負う。

保健指導は健診結果により**動機付け支援**と**積極的支援**に階層化される
（スライドには階層の別まで書かれていない）。

### 4-2. 政策背景

| 日付 | 出来事 |
|---|---|
| 2008年4月 | 特定健診・特定保健指導の開始（第1期） |
| 2024年度 | **第4期の開始**（2029年度まで） |
| 2026-07-21 | 骨太2026が予防・健康づくりの推進を掲げる |
| **2029年度** | 第4期の最終年度。全国目標は健診70%・保健指導45%（→ [p020](p020.md)） |

### 4-3. 数字の背景

- 「40歳以上75歳未満」は**高齢者医療確保法の定め**である
- 「6年ごと」の計画期間は**医療費適正化計画と同じ周期**にそろえられている（→ [p078](p078.md)）
- 検査項目は厚生労働省令で定められる

## 5. 用語

- **特定健康診査（特定健診）** — 高齢者医療確保法に基づき保険者が実施する、
  内臓脂肪型肥満に着目した健診
- **特定保健指導** — 健診結果により対象となった者に行う生活習慣改善の支援
- **BMI** — 体重(kg)÷身長(m)の2乗。肥満度の指標
- **HbA1c** — 過去1〜2か月の平均的な血糖状態を示す検査値
- **メタボリックシンドローム** — 内臓脂肪の蓄積に加え、血圧・血糖・脂質のうち
  2つ以上が基準を超える状態。特定健診はこれに着目して設計されている

## 7. 数字の読み方の注意

### ★対象は40歳以上75歳未満である 【事実】

**39歳以下は特定健診の対象ではない。**
また**75歳以上も対象外**で、後期高齢者医療広域連合が行う健康診査（努力義務）に移る
（→ [p017](p017.md)）。

保険者が義務として健診を行うのは**この35年間だけ**である。

### ★メタボリックシンドロームに特化した健診である 【解釈】

内容の欄は「高血圧症、脂質異常症、糖尿病その他の**内臓脂肪の蓄積に起因する**生活習慣病」
と限定している。
検査項目も血圧・血糖・脂質・肝機能・腹囲が中心である。

**がん検診は含まれない。**
[p015](p015.md)・[p016](p016.md)で扱われたがんは、
健康増進法に基づき市町村が行う検診の対象である（→ [p017](p017.md)）。
同じ資料の中でがんを2枚扱っておきながら、
**保険者の義務である健診にはがんが入っていない**という構造がある。

### 「やむを得ない場合」の代替項目がある 【事実】

脂質検査は空腹時中性脂肪が原則だが「やむを得ない場合は随時中性脂肪」、
血糖検査は空腹時血糖またはHbA1cが原則だが「やむを得ない場合は随時血糖」とされている。
**同じ健診でも、測られた条件が人によって違いうる。**

### 詳細な検査は医師の判断による 【事実】

心電図検査等は「一定の基準の下、医師が必要と認めた場合」に実施する。
**全員が受ける項目ではない。**

### 計画期間が6年である理由はスライドにない 【解釈】

医療費適正化計画も第4期が2024〜2029年度であり、周期がそろっている。
両者を連動させる意図と考えられる【推測】が、スライドに説明はない。

### 実施率も費用も書かれていない 【事実】

このスライドは制度の内容だけを述べる。
実績は[p020](p020.md)、財政上の位置づけは[p078](p078.md)にある。
