## 1. 一文要約

健保組合の義務的経費の44.7%が高齢者医療。頂点は2020年度の47.4%。

## 2. 書いてあること

箇条書き1行と、**棒グラフ＋折れ線1点**。横軸は1989年度から2026年度の38年分。

> ○ 健保組合の義務的経費に占める高齢者医療への拠出負担割合は、**44.7%（令和8年度予算ベース）**
> 　となっている。

### グラフの構成

棒は**2本が重ねて描かれている**（積み上げではない）。

- **白抜きの棒** ＝ **法定給付費**
- **前面の色付きの棒** ＝ **高齢者医療分**（下から
  緑＝退職者給付拠出金、橙＝前期高齢者納付金、紺＝後期高齢者支援金（老人保健拠出金））

**義務的経費 ＝ 法定給付費 ＋ 高齢者医療分**であり、
折れ線はその比率（高齢者医療分÷義務的経費）を示す。
**折れ線には目盛りがない**（二次軸のラベルなし）。

### 注記（原典より）

- ※義務的経費は、法定給付費、前期高齢者納付金（2007年度以前は退職者給付拠出金）
  及び後期高齢者支援金（2007年度以前は老人保健拠出金）の合計額。
  2008年度以降については、経過措置として存続している退職者給付拠出金及び老人保健拠出金の額も含めている。
- ※法定給付費は、2024年度までは実績額を、**2025年度及び2026年度は概算額**を用いている。
- ※後期高齢者支援金等は、2024年度までは医療給付費等実績に基づいた確定額。
  **2025年度及び2026年度は概算額**。
- ※**後期高齢者支援金について、2008・2009年度は加入者割、2010〜2014年度は3分の1総報酬割、
  2015年度は2分の1総報酬割、2016年度は3分の2総報酬割、2017年度以降は全面総報酬割**としている。
- ※前期高齢者納付金について、**2024年度以降は3分の1報酬調整**としている。
  また、前期高齢者に係る後期支援金分は前期納付金に含まれている。

## 3. このスライドの役割

[p066](p066.md)が**加入者1人当たり**の支援金だったのに対し、
本スライドは**保険者の財政に占める比重**を示す。

【解釈】「保険料の半分近くが高齢者医療に回っている」という、
**健保組合が繰り返し用いる主張の根拠**にあたるスライドである。

## 4. 背景

### 4-1. 制度背景

健保組合は次の3つを義務的に支出する。

1. **法定給付費** — 自らの加入者への保険給付
2. **後期高齢者支援金** — 後期高齢者医療制度への拠出（→ [p043](p043.md)）
3. **前期高齢者納付金** — 65〜74歳の医療費を保険者間で調整する拠出（→ [p042](p042.md)）

**総報酬割**は、支援金の按分を加入者数ではなく総報酬額に応じて行う方式である。
報酬水準の高い健保組合の負担が増える方向に働く。

### 4-2. 政策背景

| 日付 | 出来事 |
|---|---|
| 2008年度 | 後期高齢者医療制度の施行。支援金は**加入者割** |
| 2010〜2014年度 | 3分の1総報酬割 |
| 2015年度 | 2分の1総報酬割 |
| 2016年度 | 3分の2総報酬割 |
| **2017年度** | **全面総報酬割** |
| **2024年度** | **前期高齢者納付金に3分の1報酬調整を導入** |
| 2025-10-20 | 連立政権合意書が現役世代の負担軽減を掲げる |

### 4-3. 数字の背景

- **2025年度・2026年度は概算額**である。確定値ではない
- 按分方式が期間中に何度も変わっている（上記）
- 折れ線の二次軸に目盛りがない

## 5. 用語

- **義務的経費** — 法定給付費・前期高齢者納付金・後期高齢者支援金の合計。
  保健事業費などの任意の支出は含まない
- **総報酬割** — 支援金の按分を総報酬額に比例させる方式
- **前期高齢者財政調整制度** — → [kb/glossary/zenki-koureisha-zaisei-chosei.md](../../../../kb/glossary/zenki-koureisha-zaisei-chosei.md)

## 7. 数字の読み方の注意

### ★44.7%はピークではない 【事実】

箇条書きは2026年度の**44.7%**を示すが、
系列の最大値は**2020年度の47.4%**である。

| 年度 | 割合 |
|---|---|
| **2020年度** | **47.4%（最大）** |
| 2021年度 | 46.3% |
| 2022年度 | 45.5% |
| 2023年度 | 45.0% |
| 2024年度 | 45.1% |
| 2025年度 | 44.6% |
| 2026年度 | 44.7% |

**この6年間で2.7ポイント下がっている**（本解説での計算）。
箇条書きは水準だけを述べ、**直近の傾向には触れていない**【解釈】。

### ★割合が下がっても金額は増えている 【解釈】

高齢者医療分の実額は、目盛りからの読み取りで
1989年度の約1.1兆円【要確認】から2026年度の約3.9兆円【要確認】まで
**約3.5倍**に増えている（本解説での計算）。

同じ期間に法定給付費も約2.35兆円【要確認】から約4.85兆円【要確認】へ約2.1倍（同）。
**分子（高齢者医療分）の方が速く伸びているが、
直近は法定給付費の伸びが上回ったため割合が下がっている**【推測】。

**「割合が下がった」を「負担が軽くなった」と読むことはできない。**

### ★棒は積み上げではなく重ね描きである 【事実】

白抜きの棒（法定給付費）と色付きの棒（高齢者医療分）は
**同じ位置に重ねて描かれている。**
義務的経費は**2本の棒の高さの合計**であり、
**グラフの縦軸で読める最大値（白抜きの棒の高さ）ではない。**

たとえば2026年度の白抜きの棒は約4.85兆円【要確認】だが、
義務的経費は約8.75兆円【要確認】である。
**目盛りをそのまま義務的経費として読むと約半分に見誤る。**

### ★按分方式が期間中に何度も変わっている 【事実】

後期高齢者支援金の按分は、
加入者割（H20-21）→3分の1総報酬割（H22-26）→2分の1（H27）→3分の2（H28）→
全面総報酬割（2017〜）と段階的に変わった。

割合はこの間に43.5%（H20）から46.7%（H29）へ**3.2ポイント上がっている**
（本解説での計算）。
**総報酬割の拡大が健保組合の負担を押し上げた**と読める【解釈】。

さらに2024年度からは**前期高齢者納付金にも3分の1報酬調整**が入っている。
**系列は制度変更を挟んでおり、一貫した条件での比較ではない。**

### 折れ線に目盛りがない 【要確認】

二次軸のラベルがないため、**線の高さから値を読むことはできない。**
データラベルに頼るしかない。

### 2025・2026年度は概算額である 【事実】

注記のとおり、法定給付費も支援金等も**概算額**である。
箇条書きの44.7%は**確定していない年度の値**である。

### 退職者給付拠出金は経過措置である 【事実】

2007年度以前は主要な項目だったが、2008年度以降は経過措置として縮小し、
2018年度ごろにほぼゼロになっている（グラフの緑の部分）。

### 任意の支出は含まれない 【事実】

義務的経費には**保健事業費（データヘルス、特定健診等）は含まれない**。
[p018](p018.md)で扱われた予防・健康づくりの費用はこのグラフの外にある。
