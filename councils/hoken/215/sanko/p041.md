## 1. 一文要約

健保組合は支出9.3兆円のうち3.9兆円（約4割）が高齢者医療への拠出金。

## 2. 書いてあること

リード文と、**経常収入・経常支出の円グラフ2点。**

> 健保組合の経常収入は約9.3兆円、経常支出は約9.3兆円であり、支出のうち約4.8兆円（約5割）が
> 保険給付費に、約3.9兆円（約4割）が高齢者医療への拠出金に充てられている。

### 経常収入 9兆2,677億円

| 項目 | 金額 | 構成比 |
|---|---|---|
| 保険料収入 | 9.1兆円 | 98.7% |
| その他 | 0.1兆円 | 1.3% |

### 経常支出 9兆2,531億円

| 項目 | 金額 | 構成比 |
|---|---|---|
| 保険給付費 | 4.8兆円 | 51.8% |
| **高齢者医療への拠出金（介護を除く）** | **3.9兆円** | **41.7%** |
| 保健事業費 | 0.4兆円 | 4.2% |
| 事務費 | 0.1兆円 | 1.5% |
| その他 | 0.1兆円 | 0.8% |

（注）端数整理のため、計数が整合しない場合がある。

経常収支差は約146億円（9兆2,677億円−9兆2,531億円。本解説での計算）。**ほぼ収支均衡である。**

## 3. このスライドの役割

章の15枚目。[p040](p040.md)（協会けんぽ）と対になる1枚。

【解釈】2枚を並べたときの差が要点である。

| | 協会けんぽ | 健保組合 |
|---|---|---|
| 保険料収入の構成比 | 89.8% | **98.7%** |
| 国庫補助 | 9.9% | （項目なし） |
| 保険給付費の構成比 | 64.8% | **51.8%** |
| 高齢者医療への拠出金 | 32.3% | **41.7%** |

**健保組合は国庫補助がなく、支出に占める拠出金の割合が協会けんぽより9.4ポイント高い**
（本解説での引き算）。総報酬割によって報酬水準の高い健保組合の負担が重くなる構造が、
この対比に現れている（→ [kb/glossary/sohoshuwari.md](../../../../kb/glossary/sohoshuwari.md)）。

## 4. 背景

### 4-1. 制度背景

健康保険組合は、大企業やその企業グループが単独または共同で設立する保険者である。
保険者数は約1,400（→ [p028](p028.md)【要確認】）。
**国庫補助が基本的に入らない**ため、収入のほぼ全部（98.7%）が保険料である。

高齢者医療への拠出金の配分は2017年度から全面総報酬割になっており、
報酬水準が高いほど負担が重い。健保組合の加入者一人当たり平均所得は253万円【要確認】で、
協会けんぽの182万円【要確認】より高い（→ [p029](p029.md)）。

### 4-2. 政策背景

| 日付 | 出来事 |
|---|---|
| 2010年度〜 | 後期高齢者支援金の総報酬割（1/3）導入 |
| 2017年度 | 全面総報酬割。健保組合の負担が増える方向 |
| 2024年度 | 前期高齢者財政調整に報酬水準を勘案 |
| 2026-07-21 | 骨太2026「現役世代の保険料率の上昇を止め、引き下げていくことを目指す」 |

### 4-3. 数字の背景

- **2024年度決算見込**。[p040](p040.md)（協会けんぽ）は決算で、こちらは見込である
- 「経常」収入・支出であり、経常外の収支は含まない
- 介護分は除かれている
- 出典の記載はない【要確認】

## 5. 用語

- **健康保険組合** — 企業等が設立する被用者保険の保険者
- **総報酬割** — → [kb/glossary/sohoshuwari.md](../../../../kb/glossary/sohoshuwari.md)
- **経常収支** — 経常的な収入と支出。積立金の取崩し等は含まない

## 6. この事実が支える論点

このセクションは**解釈が中心**である。

### 強調表示 【事実】

原典のフォント指定を機械的に抽出すると、**太字はタイトルの1か所だけ**である。
[p040](p040.md)と同じ作りになっている。

### 逆引き 【解釈】

| 論点 | このスライドの使われ方 |
|---|---|
| 現役世代の負担軽減 | 支出の41.7%が高齢者医療への拠出金。**保険給付費（51.8%）に迫る水準** |
| 保険者間の負担調整 | 総報酬割の効果が協会けんぽとの差に現れる |
| 世代間の負担の公平 | 拠出金3.9兆円は協会けんぽ（3.6兆円）より多い。加入者数は少ないのに |

**この1枚でいちばん効く数字は 51.8% と 41.7% の近さである**【解釈】。
健保組合が集めた保険料のうち、加入者自身の給付に使われるのは半分程度で、
残りの4割強が高齢者医療に回っている。
健保組合側が制度の持続可能性を問題にする根拠は、この比率にある。

加入者数は健保組合2,803万人【要確認】、協会けんぽ3,954万人【要確認】（→ [p029](p029.md)）で
健保組合のほうが少ないのに、**拠出金の絶対額は健保組合のほうが大きい**（3.9兆円 対 3.6兆円）。
総報酬割の帰結がここに出ている【解釈】。

## 7. 数字の読み方の注意

### 「決算見込」である 【事実】

[p040](p040.md)の協会けんぽが「決算」なのに対し、こちらは「決算見込」。
**確定値ではない。**2枚を並べるときはこの差に注意する。

### 収支はほぼ均衡している 【事実】

経常収入9兆2,677億円、経常支出9兆2,531億円で差は約146億円（本解説での計算）。
協会けんぽの約6,586億円の黒字（同）とは対照的である。
**健保組合には余裕がない**という主張の根拠になりうるが、
これは全組合の合計であり、個々の組合の状況は分からない。

### 全組合の合計である 【解釈】

約1,400ある組合の合計であり、**解散に至る組合と余裕のある組合が均されている。**
組合ごとの分布はこのスライドにない。

### 介護分が除かれている 【事実】

「高齢者医療への拠出金（介護を除く）」と明記されている。介護納付金は別にある。

### 保健事業費が協会けんぽより大きい 【事実】

健保組合4.2%（0.4兆円）に対し、協会けんぽ1.5%（0.2兆円）。
**予防・健康づくりへの支出の比重が違う。**
この差の理由はスライドに書かれていない。
