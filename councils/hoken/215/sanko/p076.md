## 1. 一文要約

2008年度から2026年度までの医療保険制度改正を施行年度順に並べた整理表。

## 2. 書いてあること

**2列 × 7行グループの表**（施行年度 / 改正概要）。章扉を除けば、この章の実質的な起点にあたる一枚。

| 施行年度 | 改正概要 |
|---|---|
| 2008年度 | 高齢化により増え続ける高齢者医療費を、公費、現役世代（保険者）の支援金、高齢者の保険料で支える**高齢者医療制度を創設** |
| 2010年度 | 高齢者医療制度を支える各保険者の支援金を、頭割だけではなく、一部（1/3）所得を勘案して配分する**「総報酬割」を導入**<br>その後、順次所得を勘案する範囲を拡大し、**2017年度から全面総報酬割** |
| 2014年度 | 高額療養費制度について、現役世代（70歳未満）の所得区分の細分化（70〜74歳の2割負担導入と同時に改正）<br>**70〜74歳患者負担**について、新たに70歳になる方から**2割負担** |
| 2017年度、2018年度 | 70歳以上の高額療養費制度について、限度額引き上げ（2017年度）、現役並世帯の所得区分細分化、一般区分の外来上限額引上げ（2018年度） |
| 2022年度 | **75歳以上の一定以上所得者について2割負担**を導入<br>※課税所得28万かつ年金収入＋その他の合計所得金額200万以上（現並除く） |
| 2024年度 | **出産育児一時金**に要する費用の一部を**後期高齢者医療制度が支援**する仕組みを導入<br>**前期高齢者財政調整**についても、一部（1/3）**所得を勘案して調整**<br>「後期高齢者の一人あたり保険料」と「現役世代一人あたり支援金」の伸び率が同じになるよう**「高齢者負担率」を見直し**<br>**長期収載品**について、**後発品との差額の1／4を別途負担**する仕組みを創設 |
| 2026年度 | OTC医薬品との代替性が特に高い薬剤を用いた療養等について、薬剤費の一部を保険給付外とする一部保険外療養を創設<br>後期高齢者医療制度における金融所得の勘案<br>出産の標準的な費用に係る給付体系の見直し<br>高額療養費の支給要件等を定める際には、特に長期療養者の家計への影響が適切に考慮されるよう、法律上明確化 |

太字は原典スライド上の強調（PDFのフォント指定を機械的に抽出して確認したもの。§6で扱う）。
グラフ・図版はなく、表1点のみ。ページ右下の印刷番号は75。

## 4. 背景

### 4-1. 制度背景

表は2008年度から始まる。これは**後期高齢者医療制度の創設年度**であり、
現在の医療保険制度の骨格（公費・現役世代の支援金・高齢者の保険料の3者で高齢者医療を支える構造）が
できた年である。それ以前の改正がこの表にないのは、現在の構造の上での改正だけを並べているためと読める【解釈】。

表に並ぶ改正は、手段で分類すると3つしかない。

1. **患者の窓口負担を上げる**（2014年度の70〜74歳2割、2022年度の75歳以上一定以上所得者2割）
2. **保険者間の配分を変える**（2010年度・2017年度の総報酬割、2024年度の前期財政調整・高齢者負担率）
3. **保険給付の範囲を狭める**（2024年度の長期収載品、2026年度の一部保険外療養）

3の手法は2024年度に初めて登場し、2026年度に対象を広げている。**この資料の中で最も新しい動きである。**

### 4-2. 政策背景

| 日付 | 出来事 |
|---|---|
| 2008-04 | 後期高齢者医療制度の施行（表の起点） |
| 2023-05-19 | 全世代対応型の持続可能な社会保障制度を構築するための健康保険法等の一部を改正する法律（令和5年法律第31号）公布。表の2024年度欄3項目の根拠法 |
| 2023-12-22 | 改革工程 閣議決定（→ PDF83ページ） |
| 2026-06-05 | 健康保険法等の一部を改正する法律（令和8年法律第31号）公布。表の2026年度欄の根拠法（→ PDF82ページ） |
| 2026-08-01 | 同法のうち高額療養費に係る規定が施行 |
| 2026-09-11 | 第215回医療保険部会（本資料の配付日） |

2024年度欄と2026年度欄は、それぞれ1本の法律にひも付いている。
**表の右欄は「改正の一覧」ではなく「2本の改正法の内容を年度別に配置したもの」**という構造になっている【解釈】。

唯一の数値らしい記述は2022年度欄の適用基準（課税所得28万円、年金収入＋その他の合計所得金額200万円）で、
これは原典のテキスト層から転記した【事実】。

## 5. 用語

- **後期高齢者医療制度** — 75歳以上を対象とする独立した医療保険制度。→ [kb/glossary/kouki-koureisha-iryo-seido.md](../../../../kb/glossary/kouki-koureisha-iryo-seido.md)
- **総報酬割** — 支援金・納付金を頭数ではなく報酬総額に応じて配分する方式。→ [kb/glossary/sohoshuwari.md](../../../../kb/glossary/sohoshuwari.md)
- **高額療養費** — 1か月の窓口負担が限度額を超えた分を払い戻す仕組み。→ [kb/glossary/kogaku-ryoyohi.md](../../../../kb/glossary/kogaku-ryoyohi.md)
- **一定以上所得者** — 後期高齢者医療で2割負担が適用される区分。→ [kb/glossary/ittei-ijo-shotokusha.md](../../../../kb/glossary/ittei-ijo-shotokusha.md)
- **前期高齢者財政調整制度** — 65〜74歳の偏在による保険者間の負担差をならす仕組み。→ [kb/glossary/zenki-koureisha-zaisei-chosei.md](../../../../kb/glossary/zenki-koureisha-zaisei-chosei.md)
- **高齢者負担率** — 後期高齢者医療の給付費のうち高齢者の保険料で賄う割合。→ [kb/glossary/koureisha-futanritsu.md](../../../../kb/glossary/koureisha-futanritsu.md)
- **長期収載品** — 後発品が出た後も薬価収載され続けている先発品。→ [kb/glossary/choki-shusaihin.md](../../../../kb/glossary/choki-shusaihin.md)
- **一部保険外療養** — 薬剤費の一部を保険給付外とする2026年改正法の新制度。→ [kb/glossary/ichibu-hokengai-ryoyo.md](../../../../kb/glossary/ichibu-hokengai-ryoyo.md)
- **出産育児一時金** — 出産時に支給される定額給付。原則50万円。→ [kb/glossary/shussan-ikuji-ichijikin.md](../../../../kb/glossary/shussan-ikuji-ichijikin.md)

## 6. この事実が支える論点

このセクションは**解釈が中心**である。

### 強調表示から読めること 【事実】

原典PDFのフォント指定を機械的に抽出したところ、太字が当てられているのは次の箇所だけだった。

- 高齢者医療制度を創設
- 「総報酬割」を導入 / 2017年度から全面総報酬割
- 70〜74歳患者負担 … 2割負担
- 75歳以上の一定以上所得者について2割負担
- 出産育児一時金 … 後期高齢者医療制度が支援
- 前期高齢者財政調整 … 所得を勘案して調整
- 「高齢者負担率」を見直し
- 長期収載品 … 後発品との差額の1／4を別途負担

**太字が当たっていないのは2か所である。**

1. **高額療養費に関する記述のすべて**（2014年度の所得区分細分化、2017・2018年度の限度額引上げ）
2. **2026年度欄の4項目すべて**

### そこから引ける論点 【解釈】

- **2026年度欄に強調がない**のは、この4項目が本日（第215回）の議題そのものであり、
  事務局が結論を先取りする体裁を避けたためと読める。とくに議題①のOTC類似薬は、
  この表では「一部保険外療養を創設」という法律上の表現のままで、価値評価を含む語が置かれていない。
- **高額療養費だけ強調がない**のは、2025年に自己負担限度額の引上げをめぐって
  長期療養者への影響が問題になった経緯があるためと読める。
  2026年改正法が「特に長期療養者の家計への影響が適切に考慮されるよう法律上明確化」した
  （表の2026年度欄、およびPDF82ページ）のは、その反映である。
  この論点では、事実の提示自体に慎重さが求められている。
- 太字が集中しているのは**負担割合の引上げ**と**保険者間の配分の変更**である。
  これらは「実施済みの実績」として示しても異論が出にくい。

### 逆引き先

| 論点 | この表のどこが論拠になるか |
|---|---|
| 高齢者負担の在り方 | 2014年度・2022年度の負担引上げが、段階的に進んできた実績として示される |
| 現役世代の負担軽減 / 保険者間の負担調整 | 2010年度→2017年度の総報酬割、2024年度の前期財政調整 |
| 高齢者負担率の見直し | 2024年度欄。伸び率を揃える仕組みが導入済みであること |
| 高額療養費制度の見直し | 2014・2017・2018年度に繰り返し見直してきた実績 |
| OTC類似薬の保険給付の見直し | 2024年度の長期収載品が先例として同じ表に並んでいること |
| 医療保険における金融所得の勘案 / 出産に係る給付体系の見直し | 2026年度欄 |

**この表の最大の機能は、2024年度の長期収載品と2026年度の一部保険外療養を同じ列に並べたことにある**【解釈】。
保険給付の範囲を動かす措置が「すでに一度やったことの延長」に見える配置になっている。

## 7. 数字の読み方の注意

### この表に載っていない改正がある 【事実】

- **1997年9月の被用者本人2割、2003年4月の3割**。現役世代の負担を1割から3割まで引き上げた改正が丸ごとない。
  表が2008年度以降しか扱わないためで、これらはPDF77ページ（患者一部負担の推移）にある。
- **70〜74歳の2割負担の凍結**。2008年度に法律上は2割とされたが実際には1割に据え置かれ、
  2014年度から「新たに70歳になる方」に順次適用された。表の2014年度欄はこの再開を指しているが、
  凍結があった事実は書かれていない。PDF77ページの「※平成26年3月末までに70歳に達している者は1割」がその痕跡である。
- **国民健康保険の都道府県単位化**（2018年度）。財政運営の責任主体を都道府県に移した大きな改正だが、この表にはない。
  同じ章のPDF79ページ（保険料水準の統一）はこの改正を前提にしている。

**表に並ぶ7行は制度史の全体ではなく、事務局が選んだ抜粋である。**

### 「施行年度」と実際の施行日はずれている 【事実】

2026年度欄の4項目は、根拠法（令和8年法律第31号）では施行日がばらばらである（PDF82ページ）。

| 2026年度欄の項目 | 実際の施行 |
|---|---|
| 高額療養費の法律上明確化 | 2026年8月1日（施行済み） |
| 一部保険外療養の創設 | 公布後1年以内の政令で定める日（未施行） |
| 出産に係る給付体系の見直し | 公布後2年以内の政令で定める日（未施行） |
| 金融所得の勘案 | 公布後5年以内の政令で定める日（未施行） |

**「令和8年度」という1つの欄にまとめられているが、実際には最大で5年近い幅がある。**
この表だけを見て「令和8年度に4つの改正が施行された」と読むと誤る。

### 2024年度欄の長期収載品は年度途中（10月）の開始 【事実】

長期収載品の選定療養は2024年度の項目として並んでいるが、開始日は**2024年10月1日**である
（厚生労働省 広報誌「厚生労働」2024年10月号「今年10月1日から始まった…長期収載品の選定療養」
https://www.mhlw.go.jp/stf/houdou_kouhou/kouhou_shuppan/magazine/202410_004.html ）。
同じ欄の他の3項目は令和5年法律第31号の2024年4月1日施行分（e-Gov法令検索）であり、**半年ずれている**。
PDF75ページの2025年度「長期収載品の選定療養の拡大（▲100億円）」が、
年度途中開始分の平年度化なのか対象の拡大なのかは、この資料からは分からない【要確認】。

### 「所得を勘案」の意味が2つある 【事実】

- 2010年度・2024年度の「所得を勘案」＝**保険者の報酬水準**を勘案（総報酬割・前期財政調整）
- 2026年度の「金融所得の勘案」＝**個人の所得**を勘案（保険料算定・窓口負担割合の判定）

同じ語だが、勘案する対象が保険者か個人かで意味がまったく違う。
