## 1. 一文要約

令和8年6月5日公布の健保法等改正法の概要。この資料の現在地を示す一枚。

## 2. 書いてあること

4区画（改正の趣旨／改正の概要／施行期日／末尾の但し書き）。改正の概要は4項目に分かれ、
それぞれに根拠法の名称が【 】で併記されている。

### 改正の趣旨

> 持続可能な医療保険制度の実現に向けて、必要な保険給付等の適切な実施と世代間や世代内での
> 負担の公平性の確保を図るため、一部保険外療養の創設、後期高齢者医療における金融所得の
> 保険料等への勘案、出産に係る給付体系の見直し、国民健康保険における子どもに係る均等割
> 保険料等の軽減の拡充等の措置を講ずるほか、医療機関の業務効率化と勤務環境改善の取組等に
> 係る措置を講ずる。

### 1. より公平な負担の実現、効率的な給付の確保【健康保険法、国民健康保険法、高齢者の医療の確保に関する法律等】

1. OTC医薬品との代替性が特に高い薬剤を用いた療養等について、薬剤費の一部を保険給付外とする**一部保険外療養を創設**する。
2. 後期高齢者医療において、上場株式の配当等の**金融所得を保険料の算定や窓口負担割合等の判定に公平に反映**するため、金融所得の支払に係る報告書等（法定調書）を金融機関等がオンラインにより後期高齢者医療広域連合へ提出する義務等を設ける。

### 2. 出産等の次世代支援や現役世代からの予防・健康づくりの拡充【健保法、船員保険法、国保法、母子保健法等】

1. 出産に伴う妊婦の経済的負担を軽減するため、**出産の標準的な費用に係る給付体系の見直し**等を行う。
2. 妊婦健診に伴う妊婦の経済的負担を軽減するため、妊婦健診（望ましい基準内）の実施に係る標準額を定める等の環境の整備をするほか、サービス及び費用の見える化を進める。※こども家庭庁所管事項
3. 国民健康保険制度において、**子どもに係る均等割保険料（税）の5割を軽減する措置の対象を、未就学児から高校生年代まで拡充**する。
4. 現役世代の予防・健康づくりを強化するため、全国健康保険協会が取り組む保健事業に関する責務を明確化する。

### 3. 必要な医療の提供の確保【健保法、地域における医療及び介護の総合的な確保の促進に関する法律、医療法等】

1. **高額療養費の支給要件等を定める際には、特に長期療養者の家計への影響が適切に考慮されるよう、法律上明確化**する。
2. 業務効率化・勤務環境改善に取り組む医療機関を支援する新たな事業を地域医療介護総合確保基金に設けるほか、計画を作成し業務効率化・勤務環境改善を推進する病院を厚生労働大臣が認定する仕組みを設ける。併せて、医療機関は業務効率化・勤務環境改善に努めるものとする。

### 4. その他【健保法、国保法、高確法等】

1. 全国健康保険協会の平均保険料率の引き下げとあわせ、**令和8年度から令和10年度までの時限措置**として、全国健康保険協会への国庫補助に係る特例減額の控除額を引き上げる特例措置を講じる。
2. 国民健康保険組合に対する国庫補助について、一定の場合に、現行の補助率の下限よりも低い補助率を例外的に適用する。
3. 国民健康保険の財政安定化基金（本体基金分）について、納付金（保険料）の抑制のための取崩しを認める。　等

末尾に「このほか、平成19年の雇用保険法等の一部改正法で改正を要した船員保険法第76条第6項について、規定の形式的修正を行う。」

> 1②は公布後5年以内に政令で定める日等）

## 4. 背景

### 4-1. 制度背景

4つの項目は、動かしている対象がそれぞれ違う。

| 項目 | 動かす対象 |
|---|---|
| 1.① 一部保険外療養 | **保険給付の範囲**（何を保険で見るか） |
| 1.② 金融所得の勘案 | **負担能力の測り方**（誰にいくら求めるか） |
| 2.① 出産給付体系 | **給付の形**（定額給付をどう組み替えるか） |
| 2.③ 子ども均等割軽減 | **保険料の減免範囲** |
| 3.① 高額療養費の明確化 | **立法の際の考慮事項**（実体的な水準ではない） |
| 4.① 協会けんぽ国庫補助 | **国庫負担**（時限措置） |

1.①が最も新しい性質を持つ。**保険給付の範囲そのものを狭める措置**であり、
令和6年度の長期収載品の選定療養（PDF76ページ）に続く2例目にあたる。

## 6. この事実が支える論点

このセクションは**解釈が中心**である。

### 強調表示 【事実】

原典のフォント指定を機械的に抽出すると、太字は次の12か所のみで、**すべて見出しである。**

`健康保険法等の一部を改正する法律（令和8年法律第31号）の概要` / `改正の趣旨` / `改正の概要` / `施行期日` / `1．より公平な負担の実現、効率的な給付の確保` / `2．出産等の次世代支援や現役世代からの予防・健康づくりの拡充` / `3．必要な医療の提供の確保` / `4．その他`

**個別の措置にはひとつも強調がない。** 法律の内容を過不足なく伝える事務的な整理という体裁である。

### 逆引き 【解釈】

| 論点 | この法律での扱い |
|---|---|
| OTC類似薬の保険給付の見直し | 1.①。**法律は成立済み、実施方法が未定**。だから部会の議題になる |
| 医療保険における金融所得の勘案 | 1.②。後期高齢者医療から導入。施行は最長5年後 |
| 出産に係る給付体系の見直し | 2.①。施行は最長2年後 |
| 高額療養費制度の見直し | 3.①。**水準ではなく、水準を定めるときの考慮事項を規定した** |
| 現役世代の負担軽減 | 4.①の協会けんぽ国庫補助の特例（令和8〜10年度の時限措置） |

### 見出しの順序が示すもの 【解釈】

4項目は「より公平な負担の実現、効率的な給付の確保」から始まる。
改正の趣旨も「世代間や世代内での負担の公平性の確保」を掲げている。
**負担の公平という言葉が、給付範囲の縮小（一部保険外療養）と同じ見出しの下に置かれている**のが、
この法律の組み立て方である。

## 7. 数字の読み方の注意

### 「令和8年度の改正」は6年近くに分散する 【事実】

PDF76ページはこの法律の内容を「令和8年度」の1行にまとめているが、
施行期日は公布日（2026-06-05）から公布後5年以内（〜2031-06-04）まで広がる。
**2026年9月時点で施行済みなのは3.①（高額療養費の法律上明確化）と2④・4①だけである。**
議題①のOTC類似薬（1.①）は未施行で、実施方法もこれから決まる。

### 3.①は負担を軽くする規定ではない 【解釈】

「特に長期療養者の家計への影響が適切に考慮されるよう、法律上明確化」は、
自己負担限度額を下げる規定ではない。**支給要件等を定める際の考慮事項**を法律に書いたものである。
この規定があっても、限度額の引上げ自体は妨げられない。
【推測】令和7年に高額療養費の限度額引上げが長期療養者への影響を理由に見直された経緯を受けた
規定と読めるが、その経緯自体はこのスライドにも本資料にも書かれていない。要確認。

### 「1.② 金融所得の勘案」は所得だけで、資産は入っていない 【事実】

改革工程は「医療・介護保険における金融所得の勘案や**金融資産等の取扱い**」を課題としている（PDF83ページ）。
本法に入ったのは金融**所得**（上場株式の配当等）までで、金融**資産**の勘案は含まれていない。
またこのスライドには書かれていないが、対象は後期高齢者医療に限られている。

### 4.①の時限措置は令和10年度で切れる 【事実】

協会けんぽへの国庫補助に係る特例措置は「令和8年度から令和10年度までの時限措置」と明記されている。
**令和11年度以降の扱いは、この法律では決まっていない。**
令和10年度中に改めて議論になる見込みである【推測】。

### このスライドは概要の1ページ目でしかない 【事実】

厚生労働省が別途公開している同名の概要資料は全11ページで、
その1ページ目がこのスライドとまったく同じ内容である。
**2ページ目以降に各措置の詳細（制度の建て付け、対象範囲、具体的な仕組み）がある。**
実施方法を詰める議論を追うには、そちらを併読する必要がある。
→ https://www.mhlw.go.jp/content/12400000/001713111.pdf
