## 1. 一文要約

昭和47年から令和4年まで、患者の窓口負担割合の変遷を制度区分別に並べた一覧表。

## 2. 書いてあること

**10時期列 × 5区分行の大型マトリクス**（高齢者2行＋若人3行）。加えて上部に制度名の行がある。

時期の列は次の10本。

`～昭和47年12月｜昭和48年1月～｜昭和58年2月～｜平成9年9月～｜平成13年1月～｜平成14年10月～｜平成15年4月～｜平成18年10月～｜平成20年4月～｜令和4年10月～`

制度名の行は、`老人医療費支給制度前｜老人医療費支給制度（老人福祉法）｜老人保健制度（昭和58年2月～平成20年3月）｜後期高齢者医療制度（平成20年4月～）` と推移する。

### 注（ページ下部）

- 昭和59年に特定療養費制度を創設。将来の保険導入の必要性等の観点から、従来、保険診療との併用が認められなかった療養について、先進的な医療技術等にも対象を拡大し、平成18年に保険外併用療養費制度として再構成。
- 平成6年10月に入院時食事療養費制度創設、平成18年10月に入院時生活療養費制度創設
- 平成14年10月から3歳未満の乳幼児は2割負担に軽減、平成20年4月から義務教育就学前へ範囲を拡大

### 結合セルの確認方法 【事実】

このページはテキスト層があるが、セルの結合はテキストからは分からない。
本解説では、ページを300dpi相当のグレースケールに描画し、**罫線（縦方向に連続する暗画素の列）の位置を機械的に検出**して
結合を判定した（`build/inspect.py --grid`）。判定結果は次のとおり。

- 高齢者の行では「平成14年10月～」と「平成15年4月～」の間に罫線がない → 結合
- 75歳以上の行では「平成20年4月～」と「令和4年10月～」の間に罫線がある → 別セル
- 70〜74歳の行では同じ位置に罫線がない → 結合
- 若人の3行では「昭和48年1月～／昭和58年2月～」「平成9年9月～／平成13年1月～」「平成20年4月～／令和4年10月～」がそれぞれ結合

## 3. このスライドの役割

PDF76ページ（医療保険制度改革の経過）が平成20年度以降しか扱わないのに対し、
このスライドは**昭和47年まで遡り、患者負担だけを取り出して詳細化している**。
2枚は「対象期間」と「対象範囲」の両方でちょうど補い合う関係にある。

| | PDF76ページ | PDF77ページ（本スライド） |
|---|---|---|
| 期間 | 平成20年度〜令和8年度 | 昭和47年〜令和4年 |
| 範囲 | 患者負担・財政調整・給付範囲の全部 | 患者負担のみ |
| 形式 | 施行年度順のリスト | 時期×制度区分のマトリクス |

【解釈】この2枚を並べることで、「負担の引上げは今に始まったことではない」という含意が生まれる。
50年にわたる表のなかに令和4年10月の2割負担を置けば、それは連続した流れの最新の一点に見える。

## 4. 背景

### 4-1. 制度背景

表を縦に読むと、**高齢者と若人の負担が近づいてきた歴史**が見える。

| 時点 | 高齢者 | 若人（被用者本人） | 差 |
|---|---|---|---|
| 昭和48年1月 | なし | 定額負担 | ほぼ全額 |
| 昭和58年2月 | 定額（入院300円/日） | 1割（S59～） | 小さい |
| 平成13年1月 | 定率1割 | 2割 | 1割 |
| 平成15年4月 | 定率1割 | 3割 | 2割 |
| 令和4年10月 | 1割・2割・3割 | 3割 | 区分による |

昭和48年から平成15年までは**両者の差が開いていく**時期で、平成14年の現役並み所得者2割以降は
**再び縮める**方向に動いている。令和4年10月の一定以上所得者2割はその延長にある。

横に読むと、高齢者の負担の形が「なし → 定額 → 定率 → 所得による区分」と変わってきたことが見える。

### 4-2. 政策背景

| 日付 | 出来事 |
|---|---|
| 1973-01 | 老人医療費支給制度（老人福祉法）。高齢者の窓口負担が「なし」に |
| 1983-02 | 老人保健制度。定額負担を導入 |
| 1984 | 特定療養費制度の創設（注に記載） |
| 1994-10 | 入院時食事療養費制度の創設（注に記載） |
| 2002-10 | 現役並み所得者2割。高齢者の負担に所得の軸が入る |
| 2006-10 | 現役並み所得者3割。保険外併用療養費制度に再構成（注に記載） |
| 2008-04 | 後期高齢者医療制度。年齢で75歳以上／70〜74歳／70歳未満に3分割 |
| 2022-10 | 一定以上所得者2割 |
| 2023-12-22 | 改革工程が「医療・介護の3割負担（現役並み所得）の適切な判断基準設定等」を検討課題に |

**表は令和4年10月で終わっている。** 改革工程が挙げる次の見直し（3割負担の判断基準）は、この表の右側に来る。

### 4-3. 数字の背景

統計ではなく制度の記述であり、出典の記載はない。
昭和58年・平成9年の定額負担の金額（300円/日、400円/月、1,000円/日、500円/日）は
テキスト層から転記した【事実】。

## 6. この事実が支える論点

このセクションは**解釈が中心**である。

### 強調表示 【事実】

原典PDFのフォント指定を機械的に抽出したところ、**このページには太字が1か所もない。**
タイトルさえ太字でない（他のスライドはタイトルが太字）。色による強調も赤枠もない。

【解釈】同じ章のPDF76ページが8か所を太字にしているのと対照的である。
このページは事務局の読ませたい方向を示さず、**中立な参照表として置かれている**と読める。
負担引上げの歴史を並べること自体に説得力があるため、強調が不要だったとも考えられる【推測】。

### 逆引き 【解釈】

| 論点 | この表のどこが論拠になるか |
|---|---|
| 高齢者負担の在り方 | 高齢者の負担が「なし → 定額 → 定率 → 所得区分」と段階的に動いてきた事実。次の一歩も同じ延長線にあると位置付けられる |
| 世代間の負担の公平 | 高齢者と若人の負担の差が、時期によって開いたり縮んだりしてきたこと |
| 高額療養費制度の見直し | 昭和48年の創設以来、負担割合の引上げと高額療養費の整備が対で動いてきたこと |

**この表が支えているのは、個別の数字ではなく「方向性の連続性」である。**

## 7. 数字の読み方の注意

### 「割合」だけの表であり、実際の負担額は分からない 【事実】

窓口負担割合は上限ではない。高額療養費の自己負担限度額が同時に効くため、
**負担割合が3割でも、実際に払う額は限度額で頭打ちになる。**
表には「高額療養費創設（S48～）」としか書かれておらず、限度額の水準の推移は載っていない。
限度額の水準はPDF34ページ（70歳以上の所得区分ごとの窓口負担割合・高額療養費）にある。

たとえば「昭和48年の被用者家族5割 → 現在3割」は負担が軽くなったように見えるが、
医療費の絶対額が当時とは違うため、家計への負担の比較にはならない。

### 70〜74歳の2割負担には凍結期間があった 【事実】

平成20年4月の欄は「2割負担（現役並み所得者3割）」だが、※書きで
「平成26年3月末までに70歳に達している者は1割（平成26年4月以降70歳になる者から2割）」とある。
**法律上は平成20年から2割だったが、実際の適用は平成26年4月から段階的に始まった。**
表の見出しの年月と、実際に負担が変わった年月は一致していない。

### 時期の区切り方が制度区分ごとに違う 【事実】

罫線を機械検出した結果、高齢者の行と若人の行ではセルの結合が異なっていた。
高齢者は平成13年1月・平成14年10月・平成18年10月で区切られるのに対し、
若人は平成15年4月・平成18年10月・平成20年4月で区切られる。
**同じ列に並んでいても、同じ時点の話をしているとは限らない。**

### 若人の「薬剤一部負担の廃止」の時点 【要確認】

若人の「3割／薬剤一部負担の廃止」のセルは、罫線の位置が
「平成14年10月～」と「平成15年4月～」の境界にまたがっており、どちらの時期に属するか
幾何学的には確定できなかった。セルの右端は「平成15年4月～／平成18年10月～」の境界と
一致しているため、本解説では**平成15年4月～**として整理した。
なお3歳未満の乳幼児2割（平成14年10月）は、その1つ左のセルの中に注記されている。

### この表にないもの 【事実】

- 入院時食事療養費・生活療養費の自己負担額（注に制度創設の記載があるだけ）
- 高額療養費の自己負担限度額の水準
- 保険料の負担
- 令和6年度の長期収載品の選定療養、令和8年度の一部保険外療養

後ろの2つは「窓口負担割合」ではなく「給付範囲」を動かす措置であるため、
この表の枠組みでは表現できない。**患者が実際に払う額は、この表の外側でも動いている。**
