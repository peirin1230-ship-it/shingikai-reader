## 1. 一文要約

後期高齢者医療19.5兆円を公費47％・支援金40％・保険料で賄う内訳図。

## 2. 書いてあること

中央に**積み上げ棒1本**、左右に個別制度の説明。2026年度予算ベース。

### 医療給付費等総額 約19.5兆円

| 財源 | 割合 | 金額 |
|---|---|---|
| **支援金**（現役世代からの後期高齢者支援金） | **40%** | 7.7兆円 |
| 定率国庫負担 | 24% | 4.6兆円 |
| 国調整交付金 | 8% | 1.5兆円 |
| 定率都道府県負担 | 8% | 1.5兆円 |
| 定率市町村負担 | 8% | 1.5兆円 |
| **保険料**（高齢者本人） | — | **1.9兆円** |

図の上部に「53%／47%」の区分が示されている。

> ※ 現役並み所得を有する高齢者の医療給付費には公費負担がなく、その分は現役世代の支援金による
> 負担となっていることから、**公費負担割合は47%**となっている。

### 個別の制度

| 制度 | 内容 | 規模 |
|---|---|---|
| 財政安定化基金 | 保険料未納リスク、給付増リスクに対応。国・都道府県・広域連合（保険料）が1/3ずつ拠出して都道府県に基金を設置し、貸付等を行う | 0.2兆円程度（基金残高） |
| 高額医療費に対する支援 | 85万円を超えるレセプトに係る医療費の一定部分について、国・都道府県が1/4ずつ負担 | 0.5兆円 |
| 特別高額医療費共同事業 | 1件400万円を超えるレセプトに係る医療費の200万円超分について財政調整（国費10億円） | — |
| 調整交付金（国） | 普通調整交付金（9/10）＝広域連合間の所得格差による財政力不均衡の調整／特別調整交付金（1/10）＝災害その他特別の事情 | 1.5兆円 |
| 保険基盤安定制度 | 低所得者等の保険料軽減（均等割7割・5割・2割軽減、被扶養者の5割軽減（資格取得後2年間分））＜市町村1/4、都道府県3/4＞ | 0.4兆円程度 |

運営主体は都道府県単位の広域連合。

## 3. このスライドの役割

章の17枚目。[p042](p042.md)（国保）と対になる1枚で、**世代間移転の受け手側**を示す。

【解釈】この図は、[p040](p040.md)[p041](p041.md)の「高齢者医療への拠出金」が
どこへ行くかの答えである。

```
協会けんぽ 3.6兆円 ┐
健保組合  3.9兆円 ├─→ 後期高齢者医療の支援金 7.7兆円（40%）
共済組合ほか     ┘
```

**現役世代の拠出金がほぼそのまま支援金7.7兆円に対応する**（3.6＋3.9＝7.5兆円。本解説での足し算。
共済組合分と前期高齢者納付金分があるため完全には一致しない）。

## 4. 背景

### 4-1. 制度背景

後期高齢者医療の財源構成は、公費約5割・支援金4割・保険料1割が原則である。
このスライドの47%／40%／残りという構成はその実額にあたる。

保険料1.9兆円は医療給付費等総額19.5兆円の約9.7%（本解説での計算）。
**高齢者本人の保険料は全体の1割弱**である。

この「高齢者負担率」を動かす仕組みが2024年度に見直された
（→ [kb/glossary/koureisha-futanritsu.md](../../../../kb/glossary/koureisha-futanritsu.md)）。

### 4-2. 政策背景

| 日付 | 出来事 |
|---|---|
| 2008-04 | 後期高齢者医療制度の創設 |
| 2024年度 | 高齢者負担率の見直し（保険料と支援金の伸び率を揃える） |
| 2026-06-05 | 令和8年法律第31号 1.②。後期高齢者医療における金融所得の勘案 |
| 2026-07-07 | **骨子 項目2**が後期高齢者医療制度の運営主体の在り方を2028年末までに結論と明記 |

**★この図の「都道府県単位の広域連合」という運営主体そのものが見直しの対象である。**

## 6. この事実が支える論点

このセクションは**解釈が中心**である。

### 強調表示 【事実】

太字の抽出結果はごく少なく、**個別の数値に強調はない。**

### 逆引き 【解釈】

| 論点 | この図のどこが論拠になるか |
|---|---|
| 高齢者負担の在り方 | 保険料1.9兆円が総額の1割弱であること |
| 現役世代の負担軽減 | 支援金40%（7.7兆円）。高齢者本人の保険料の4倍 |
| 世代間の負担の公平 | 支援金7.7兆円 対 保険料1.9兆円という4対1の構図 |
| 高齢者負担率の見直し | この比率をどう動かすかが論点そのもの |

**「支援金は高齢者本人の保険料の4倍」という対比が、この図でいちばん強い**【解釈】。
7.7÷1.9＝約4.1倍（本解説での計算）。
現役世代側が制度の持続可能性を問題にする根拠がここにある。

一方で、後期高齢者の一人当たり所得は94万円【要確認】（→ [p029](p029.md)）であり、
保険料負担率は8.4%【要確認】と組合健保の5.7%【要確認】より高い。
**「保険料が少ない」と「負担が軽い」は同じではない**【解釈】。

## 7. 数字の読み方の注意

### 公費が47%である理由 【事実】

※が明記している。「現役並み所得を有する高齢者の医療給付費には公費負担がなく、
その分は現役世代の支援金による負担となっている」。
**原則5割だが、現役並み所得者の分は支援金が肩代わりしている。**
支援金40%のうち一部は、本来公費が担うはずだった部分である。

### 時点が制度ごとに違う 【事実】

このスライドは2026年度予算ベース、[p042](p042.md)は2027年度概算要求ベース、
[p040](p040.md)は2024年度決算、[p041](p041.md)は2024年度決算見込。
**4枚を足し合わせて全体像を作ることはできない。**

### 保険料1.9兆円に軽減分が含まれるか 【要確認】

保険基盤安定制度（0.4兆円程度）で低所得者の保険料が軽減されている。
この軽減分が1.9兆円に含まれるのか別なのかは、図からは判断できない。

### 「医療給付費等総額」に何が含まれるか 【要確認】

「等」が何を指すか（高額医療費への支援や事務費を含むか）は明記されていない。
[p028](p028.md)の「約19兆円【要確認】」（2026年度予算ベース）とほぼ一致するが、
範囲が同じかは確認できない。

### 基金残高と単年度の額が混在している 【事実】

財政安定化基金の0.2兆円は**基金残高**であり、単年度の支出ではない。
他の金額（0.5兆円、0.4兆円など）と性質が違う。
