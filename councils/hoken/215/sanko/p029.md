## 3. このスライドの役割

章の3枚目。[p028](p028.md)が制度の並びを図で示したのに対し、
**本スライドは同じ並びを数値で埋める。**

【解釈】この1枚があることで、制度間の議論が具体的になる。
「高齢者は医療費が高い」も「現役世代の負担が重い」も「国保は所得が低い」も、
すべてこの表の行を指させば済む。**この資料で最も引用されやすい一枚**である。

## 4. 背景

### 4-1. 制度背景

5つの保険者は、成り立ちも加入者の属性もまったく違う。
表の3行目（平均年齢）と6行目（平均所得）を並べると、その差が数字で出る。

| | 平均年齢 | 一人当たり所得 | 一人当たり医療費 |
|---|---|---|---|
| 組合健保 | 36.1歳【要確認】 | 253万円【要確認】 | 19.3万円【要確認】 |
| 市町村国保 | 54.0歳【要確認】 | 99万円【要確認】 | 41.7万円【要確認】 |
| 後期高齢者 | 82.7歳【要確認】 | 94万円【要確認】 | 96.4万円【要確認】 |

**所得が低く医療費が高い制度と、所得が高く医療費が低い制度に分かれている。**
これが財政調整（支援金・納付金・公費）が必要になる理由そのものである。

### 4-2. 政策背景

| 日付 | 出来事 |
|---|---|
| 2010年度〜 | 後期高齢者支援金に総報酬割を導入（→ [p076](p076.md)） |
| 2017年度 | 全面総報酬割 |
| 2024年度 | 前期高齢者財政調整に報酬水準を勘案 |
| 2026-07-07 | 骨子 項目2が保険者の再編統合を検討課題に |
| 2026-07-21 | 骨太2026が現役世代の保険料率の引下げを明記 |

### 4-3. 数字の背景

- **時点がそろっていない。** 保険者数・加入者数は令和6年3月末、平均年齢は令和5年度9月末、
  医療費・所得・保険料は令和5年度、公費負担額は令和8年度予算ベース
- 所得の定義が制度で違う（※2）。市町村国保・後期高齢者は税務上の所得、
  被用者保険は標準報酬総額から給与所得控除相当額を除いた**参考値**
- 保険料に介護分は含まない（※4）
- 公費負担額に介護納付金・特定健診等への補助は含まない（※5）

**最も使われるのは「保険料負担率」の行だと考えられる**【解釈】。
所得に対する保険料の重さを制度横断で比べられる唯一の指標で、
市町村国保9.3%【要確認】が最も高く、組合健保5.7%【要確認】が最も低い。
負担の公平を論じるとき、どちらの側からもこの行が引かれる。

## 7. 数字の読み方の注意

### ★すべての数値が未検証である 【要確認】

抽出9字のページであり、本解説の数値はすべて画像からの読み取りである。
**この資料で最も読み取り誤りが起きやすい一枚**で、`number_verified: false` を維持している。
SPEC §6 の品質ルール3により、人が原典と照合するまでこの表の数値を引用してはいけない。

### 所得の定義が制度で違う 【事実】

※2が長い注釈を付けているとおり、
市町村国保・後期高齢者は税務上の所得、被用者保険は報酬から控除相当額を除いた**参考値**である。
**「組合健保253万円【要確認】、市町村国保99万円【要確認】」を所得の実額として比べるのは危うい。**
被用者保険側は賞与を含む標準報酬総額ベースであり、国保側は必要経費控除後の所得である。

### 保険料の比べ方が3通りある 【事実】

7行目には「加入者一人当たり」「被保険者一人当たり」「〈事業主負担込〉」の3系統が混在する。

- 加入者一人当たり＝被扶養者を含めて割った額
- 被保険者一人当たり＝実際に保険料を払う人で割った額
- 〈 〉＝事業主負担を含めた額

**どれを使うかで倍以上変わる。** 組合健保は加入者一人当たり14.4万円【要確認】だが、
被保険者一人当たり事業主負担込では52.8万円【要確認】である。

### 時点がそろっていない 【事実】

4-3に書いたとおり、行ごとに時点が違う。
とくに公費負担額だけが**令和8年度予算ベース**で、他は令和5年度・令和6年3月末である。
**一覧表に見えるが、同じ時点の断面ではない。**

### [p028](p028.md)と数字が合わない 【事実】

| | p028（令和8年度予算ベース） | p029（令和6年3月末） |
|---|---|---|
| 国保の加入者数 | 約2,460万人【要確認】 | 2,309万人【要確認】 |
| 後期高齢者の加入者数 | 約2,100万人【要確認】 | 1,978万人【要確認】 |
