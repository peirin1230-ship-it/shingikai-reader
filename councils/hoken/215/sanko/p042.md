## 1. 一文要約

国保の医療給付費10.2兆円を、保険料・公費・前期交付金で賄う内訳図。

## 2. 書いてあること

中央に**積み上げ棒1本**（医療給付費等総額の財源内訳）、左右に各制度の説明。
単位は100億円。令和9年度概算要求ベース。

### 医療給付費等総額：約101,700億円

| 財源 | 金額 | 割合 |
|---|---|---|
| 保険料 | 22,200億円 | （50%側） |
| 法定外一般会計繰入 | 約1,200億円 ※2 | 同上 |
| 定率国庫負担 | 20,600億円 | 32% ※1 |
| 調整交付金（国） | 7,600億円 | 9% ※1 |
| 都道府県繰入金 | 5,800億円 | 9% ※1 |
| **前期高齢者交付金** | **33,500億円 ※3** | — |

図では公費50%／保険料50%の区分線が引かれている。

### 公費負担額：45,000億円

| 内訳 | 金額 |
|---|---|
| 国 計 | 32,100億円 |
| 都道府県計 | 11,000億円 |
| 市町村計 | 1,900億円 |

### 個別の制度（図の左右に配置）

| 制度 | 内容 | 規模 |
|---|---|---|
| 保険者努力支援制度 | 都道府県・市町村の医療費適正化、予防・健康づくり等の取組状況に応じ支援 | 予算額：約1,300億円 |
| 特別高額医療費共同事業 | 著しく高額な医療費（1件420万円超）を都道府県からの拠出金を財源に全国で調整 | 国庫補助額：60億円 |
| 高額医療費負担金 | 高額な医療費（1件90万円超）の影響緩和。国と都道府県が1/4ずつ負担 | 事業規模3,700億円、国庫補助額900億円 |
| 子ども保険料軽減制度 | 未就学児の均等割保険料の5割を公費で支援 | 事業規模80億円、国庫補助額40億円（国1/2、都道府県1/4、市町村1/4） |
| 保険者支援制度 | 低所得者数に応じ保険料額の一定割合を公費で支援 | 事業規模2,900億円、国庫補助額1,400億円（同上） |
| 財政安定化支援事業 | 市町村への地方財政措置 | 1,000億円 |
| 普通調整交付金（7%） | 都道府県間の財政力の不均衡を調整 | — |
| 特別調整交付金（2%） | 災害等の特別の事情を考慮して交付 | — |
| 前期高齢者交付金 | 65〜74歳の前期高齢者の偏在による保険者間の負担の不均衡を、加入者数に応じて調整 | — |
| 産前産後保険料免除制度 | 産前産後期間相当分の均等割・所得割保険料を公費で支援 | 事業規模15億円、国庫補助額8億円（国1/2、都道府県1/4、市町村1/4） |
| 低所得者保険料軽減制度 | 低所得者の保険料軽減分を公費で支援 | 事業規模4,600億円（都道府県3/4、市町村1/4） |

- ※1 それぞれ保険給付費等の9%、32%、9%の割合を基本とするが、定率国庫負担等のうち一定額について、財政調整機能を強化する観点から国の調整交付金に振りかえる等の法律上の措置がある
- ※2 令和5年度決算における決算補填等の目的の一般会計繰入の額
- ※3 退職被保険者を除いて算定した前期高齢者交付金額であり、実際の交付額とは異なる

## 3. このスライドの役割

章の16枚目。[p040](p040.md)[p041](p041.md)が被用者保険の財政を示したのに対し、
本スライドは**国保の財政**を示す。

【解釈】被用者保険の円グラフが2要素（保険料・給付）でほぼ説明できたのに対し、
国保の図は制度が11個並ぶ。**同じ「医療保険」でも構造の複雑さがまるで違う。**
保険料だけでは賄えないため、公費と財政調整の仕組みが幾重にも積み上がっている。

## 4. 背景

### 4-1. 制度背景

国保は加入者の平均年齢が54.0歳【要確認】、平均所得が99万円【要確認】と
被用者保険より高齢・低所得である（→ [p029](p029.md)）。
そのため保険料だけでは給付を賄えず、**給付費等の約50%が公費**である。

さらに前期高齢者交付金が33,500億円【要確認】入っている。
これは被用者保険から国保へ移転する金であり、
[p040](p040.md)[p041](p041.md)の「高齢者医療への拠出金」の一部がここに来る。

**被用者保険の支出と国保の収入は、同じ金の裏表である**【解釈】。

### 4-2. 政策背景

| 日付 | 出来事 |
|---|---|
| 2018年度 | 国保の都道府県単位化 |
| 2024年度 | 前期高齢者財政調整に報酬水準を勘案（→ [p076](p076.md)） |
| 2023-12-22 | 改革工程が「国保の普通調整交付金の医療費勘案等」を2028年度までの検討課題に |
| 2026-06-05 | 令和8年法律第31号 2.③。子ども均等割軽減の対象を未就学児から高校生年代まで拡充／4.③ 財政安定化基金の取崩し |
| 2026-07-07 | 骨子 項目2が保険料水準の完全統一の前倒しを明記 |

**★この図の「子ども保険料軽減制度」が令和8年法律第31号で拡充される。**
現在は未就学児（事業規模80億円）が対象で、高校生年代まで広がる（→ [p082](p082.md)）。

### 4-3. 数字の背景

- **令和9年度概算要求ベース**。予算でも決算でもなく要求段階の数値である
- ※3のとおり、前期高齢者交付金は退職被保険者を除いた算定で**実際の交付額とは異なる**
- ※2の法定外一般会計繰入は令和5年度決算の額で、他と時点が違う

## 5. 用語

- **保険者努力支援制度** — 取組に応じて交付金を配分する仕組み（→ [p080](p080.md)）
- **普通調整交付金／特別調整交付金** — 国の調整交付金（合わせて9%）
- **前期高齢者交付金** — → [kb/glossary/zenki-koureisha-zaisei-chosei.md](../../../../kb/glossary/zenki-koureisha-zaisei-chosei.md)
- **財政安定化支援事業** — 市町村への地方財政措置

## 6. この事実が支える論点

このセクションは**解釈が中心**である。

### 強調表示 【事実】

太字の抽出結果はタイトルを含めごく少なく、**個別の数値に強調はない。**
制度の一覧を中立に示す図である。

### 逆引き 【解釈】

| 論点 | このスライドの使われ方 |
|---|---|
| 保険者間の負担調整 | 前期高齢者交付金33,500億円【要確認】が、被用者保険から国保への移転の実額 |
| 医療費適正化 | 保険者努力支援制度（約1,300億円）が取組に応じた配分の仕組み |
| 現役世代の負担軽減 | 国保の公費45,000億円と前期交付金33,500億円をどう組み替えるかが論点 |

**前期高齢者交付金が公費45,000億円に迫る規模であることが、この図の要点である**【解釈】。
33,500億円【要確認】は公費の7割強にあたる（33,500÷45,000＝約74%。本解説での計算）。
国保の財政は、公費と被用者保険からの移転の**両方**に依存している。

改革工程と骨太2026が「国保の普通調整交付金の医療費勘案等」を課題に挙げているのは、
この図の調整交付金（9%・7,600億円）の配り方の話である。

## 7. 数字の読み方の注意

### 概算要求ベースである 【事実】

**令和9年度の概算要求段階の数値**であり、予算でも決算でもない。
[p040](p040.md)（令和6年度決算）や[p043](p043.md)（令和8年度予算ベース）とは
時点も段階も違う。**並べて比較できない。**

### 前期高齢者交付金は実際の額と違う 【事実】

※3が明記している。「退職被保険者を除いて算定した前期高齢者交付金額であり、
実際の交付額とは異なる」。**33,500億円をそのまま実額として使ってはいけない。**

### 公費50%の内訳が単純ではない 【事実】

※1のとおり、定率国庫負担32%・調整交付金9%・都道府県繰入金9%が基本だが、
「定率国庫負担等のうち一定額について、財政調整機能を強化する観点から
国の調整交付金に振りかえる等の法律上の措置がある」。
**表示された割合どおりに配分されているとは限らない。**

### 法定外一般会計繰入の時点が違う 【事実】

※2のとおり令和5年度決算の額である。他が令和9年度概算要求ベースであるなか、
この項目だけ4年前の実績が使われている。

### 個別制度の規模はごく小さい 【解釈】

子ども保険料軽減制度80億円、産前産後保険料免除制度15億円など、
図の左右に並ぶ制度の多くは医療給付費等総額（約101,700億円）に比べると桁が2〜3つ小さい。
**図の面積と財政規模は対応していない。**
