## 1. 一文要約

後発医薬品の数量シェアが32.5%から88.8%まで上がった20年分の折れ線。

## 2. 書いてあること

**折れ線グラフ1点のみ。** 縦軸は30%〜90%（10%刻み）、横軸は薬価調査の実施時点。
系列は1本で、各点に数値ラベルが付いている。

| 時点 | 使用割合 |
|---|---|
| 2005.9（2005.9） | 32.5% |
| 2007.9（2007.9） | 34.9% |
| 2009.9（2009.9） | 35.8% |
| 2011.9（2011.9） | 39.9% |
| 2013.9（2013.9） | 46.9% |
| 2015.9（2015.9） | 56.2% |
| 2017.9（2017.9） | 65.8% |
| 2018.9（2018.9） | 72.6% |
| 2019.9（2019.9） | 76.7% |
| 2020.9（2020.9） | 78.3% |
| 2021.9（2021.9） | 79.0% |
| 2022.9（2022.9） | 79.0% |
| 2023.9（2023.9） | 80.2% |
| 2024.9（2024.9） | 85.0% |
| 2025.9（2025.9） | **88.8%** |

凡例・注記・目標線はない。出典の明記もタイトルの「薬価調査における」だけである。

## 3. このスライドの役割

個別の手段を並べる4枚（78〜81）の最後で、**章のなかで唯一の薬剤の話**である。

【解釈】直後の[p082](p082.md)が令和8年法律第31号（一部保険外療養＝OTC類似薬）の概要なので、
**「薬剤で医療費を抑える手段はここまで来た」→「だから次はOTC類似薬」**という並びになっている。
後発医薬品への置き換えという手段が上限に近づいていることを示したうえで、
給付範囲そのものを動かす次の手を出す構成である。

## 4. 背景

### 4-1. 制度背景

後発医薬品（ジェネリック）への置き換えは、同じ効能の薬をより安く使うことで
薬剤費を抑える手段である。診療報酬上の加算、保険者による差額通知、
処方箋様式の変更などを積み重ねて進められてきた。

数量シェアが8割を超えると、**置き換えで得られる余地はほとんど残らない。**
そこで手段は次の2つに移る。

1. **長期収載品の負担を変える** — 2024年度に、後発品がある先発品を選んだ場合に
   差額の4分の1を選定療養として別途負担する仕組みを創設（→ [p076](p076.md)）。
   2025年度にはその対象が拡大（制度改正による減▲100億円。→ [p075](p075.md)）
2. **保険給付の範囲そのものを狭める** — 2026年度の一部保険外療養（→ [p082](p082.md)）

### 4-2. 政策背景

| 日付 | 出来事 |
|---|---|
| 2005.9 | グラフの起点（32.5%） |
| 2018年度 | 薬価制度の抜本改革（制度改正による減▲1,300億円。→ [p075](p075.md)） |
| 2024年度 | 長期収載品の選定療養を創設 |
| 2025-06-11 | 三党合意がOTC類似薬の保険給付の見直しを「令和8年度から実行する」と明記 |
| 2026-06-05 | 令和8年法律第31号 公布（一部保険外療養） |
| 2026-07-21 | 骨太2026が2027年度以降の対象範囲の拡大に向けた検討を明記 |

### 4-3. 数字の背景

- **出典は薬価調査。** 薬価改定の基礎資料として厚生労働省が行う調査で、毎年9月に実施される
- 数量ベースであり、金額ベースではない。**後発品は単価が安いので、金額シェアはこれより低くなる**
- 2005年から2017年までは隔年、2018年以降は毎年の点である

## 5. 用語

- **後発医薬品（ジェネリック）** — 先発医薬品の特許満了後に、同一の有効成分で製造・販売される医薬品
- **長期収載品** — 後発品が出た後も薬価収載され続けている先発品。→ [kb/glossary/choki-shusaihin.md](../../../../kb/glossary/choki-shusaihin.md)
- **選定療養** — 患者が自ら選んで追加負担する療養。→ [kb/glossary/sentei-ryoyo.md](../../../../kb/glossary/sentei-ryoyo.md)

## 6. この事実が支える論点

このセクションは**解釈が中心**である。

### 強調表示 【事実】

太字はタイトルと**15個の数値ラベルすべて**。線や特定の年に強調はない。
数字そのものを読ませる作りである。

### 逆引き 【解釈】

| 論点 | このスライドの使われ方 |
|---|---|
| OTC類似薬の保険給付の見直し | 後発品への置き換えが8割を超え、**この手段の伸びしろが小さくなった**ことを示す |
| 医療費適正化 | 第4期医療費適正化計画の「後発医薬品及びバイオ後続品の使用促進」の実績（→ [p078](p078.md)） |

**この1枚が置かれている理由は、上がったことを示すためだけではない**【解釈】。
88.8%という水準は、裏返せば**残りが11.2%しかない**ということでもある。
次の手段に移る根拠として読むこともできる配置になっている。

## 7. 数字の読み方の注意

### 縦軸が30%から始まっている 【事実】

0%起点ではないため、**伸びが実際より急に見える。**
32.5%→88.8%は2.7倍だが、グラフ上の高さの比はそれよりずっと大きく見える。

### 横軸の間隔が途中で変わる 【事実】

2005.9〜2017.9は**隔年**、2018.9以降は**毎年**の点である。
グラフ上は等間隔に並んでいるので、
**2005〜2017の12年間と2017〜2025の8年間が同じくらいの幅で描かれている。**
左半分の傾きと右半分の傾きを直接比べてはいけない。

### 2020〜2022年に踊り場がある 【事実】

78.3% → 79.0% → 79.0% と3年間ほぼ横ばいで、2022.9は前年と同じ79.0%。
そのあと2023.9に80.2%、2024.9に85.0%、2025.9に88.8%と再び伸びている。
**この踊り場と再加速が何によるものかは、このスライドからは分からない。**
後発医薬品の供給不安の影響、長期収載品の選定療養の導入（2024年度）などが
考えられるが、いずれもスライドに記載はない【推測】。

### 数量ベースであることを忘れない 【事実】

タイトルに「（数量ベース）」と明記されている。
**金額ベースのシェアはこれより大幅に低い。**
薬剤費の削減額を論じるときに数量シェアをそのまま使うと過大評価になる。
薬剤費の実額は[p060](p060.md)（国民医療費、薬剤費等の推移）にある。

### 目標値が書かれていない 【事実】

政府は後発医薬品の使用割合について数量シェアの目標を掲げてきたが、
**このスライドには目標線も達成状況も書かれていない。**
どの水準を目指しているのかは、この1枚だけでは読めない【要確認】。
