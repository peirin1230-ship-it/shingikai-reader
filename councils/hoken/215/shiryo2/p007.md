## 1. 一文要約

「攻めの予防医療」で健康寿命の延伸を図る。施策の列挙で数値目標はない。

## 2. 書いてあること

骨太2026 第3章2. のうち、**（攻めの予防医療と疾病対策）**の段落。
本文2段落と注135〜注142。図表はない。

**第1段落（攻めの予防医療）**

> 国民のWell-beingの向上と**健康寿命の延伸**を図り、誰もが社会の担い手として
> 活躍できる日本を実現する。「**攻めの予防医療**」を推進し、健康増進、
> 肥満症を含む疾病予防、**早期発見、早期介入及び行動変容**に関係機関が連携して取り組む。

続けて、取り組む項目が列挙される。

| 分野 | 列挙されている項目 |
|---|---|
| リテラシー | 栄養・食生活を含む健康リテラシーの向上 |
| 薬局 | 地域住民の健康増進に資する**薬局機能及び薬剤師の役割の強化** |
| 学齢期 | **学齢期の健康診断の在り方の見直し**（注135） |
| 感染症 | 予防接種、HIVや性感染症の予防、**下水サーベイランス**等 |
| がん | **がん検診や精密検査の受診率向上** |
| 生活習慣病 | 循環器病・糖尿病を含む生活習慣病等の予防 |
| 歯科 | いわゆる**国民皆歯科健診**の具体化（**歯周病検診の対象拡大**や**就労世代の歯科健診**の更なる充実）、口腔と全身の健康の関係に基づく歯科疾患対策・口腔健康管理（注136） |
| 認知症 | 認知症の早期診断・早期対応 |
| リハビリ | 予防・医療・介護を通じた切れ目のないリハビリテーション（注137） |
| データ | **PHRの利活用と情報連携** |
| 女性の健康 | 更年期世代の女性への医療、女性の健康総合センターの機能強化、**プレコンセプションケア推進5か年計画**（注138）の工程表の策定と実行 |
| 職域 | 企業と保険者の**コラボヘルス**、睡眠対策を含む**健康経営**の推進等（注139） |

**第2段落（疾病対策）**

> がん、脳卒中・心臓病その他の循環器病、慢性腎臓病、慢性閉塞性肺疾患、慢性疼痛、難病、
> アレルギー、依存症、難聴、睡眠障害等の**疾病対策**（注142）や**移植医療対策**を推進する。

> ※141 「性差に由来する健康課題等への対応を推進するための論点整理」

> ※142 先進医療で実施しているがん遺伝子パネル検査の標準治療開始前からの受診機会の拡大を含む。

## 3. このスライドの役割

骨太2026抜粋の6枚目。[p006](p006.md)の創薬に続く段落で、
**予防・健康づくり**を扱う。

【解釈】医療保険部会にとっての接点は3つである。

1. **健康寿命の延伸**は、注126（→ [p005](p005.md)）が窓口負担見直しの
   考慮要素として挙げた4つのうちの1つである
2. **コラボヘルス**は保険者（健保組合・協会けんぽ）の事業である
3. **保険者努力支援制度**を通じて、予防の取組が国保の財政に反映される

## 4. 背景

### 4-1. 制度背景

**健康寿命**は「健康上の問題で日常生活が制限されることなく生活できる期間」である
（→ [参考資料 p008](../sanko/p008.md)）。

**特定健診・特定保健指導**は40〜74歳の被保険者・被扶養者を対象とし、
保険者に実施義務がある（→ [kb/glossary/tokutei-kenshin.md](../../../../kb/glossary/tokutei-kenshin.md)）。

**コラボヘルス**は、事業主（労働安全衛生法の健診）と保険者（特定健診）が
データを持ち寄って協働する取組を指す。
保険者側の取組は**保険者努力支援制度**（→ [kb/glossary/hokensha-doryoku-shien.md](../../../../kb/glossary/hokensha-doryoku-shien.md)）の
評価指標に組み込まれている。

### 4-2. 政策背景

| 日付 | 出来事 |
|---|---|
| 2008-04 | 特定健診・特定保健指導の開始 |
| 2025-05-22 | プレコンセプションケア推進5か年計画（注138） |
| 2026-05-25 | 性差に由来する健康課題等への対応の論点整理（注141） |
| **2026-07-21** | **骨太2026 閣議決定（このページ）** |

### 4-3. 数字の背景

**このページには統計数値が1つも出てこない。**
「5か年計画」という計画の名称に含まれる5が唯一の数字である。

健康寿命・平均寿命の実数は[参考資料 p007](../sanko/p007.md)・[p008](../sanko/p008.md)にある。

## 5. 用語

- **特定健診・特定保健指導** — → [kb/glossary/tokutei-kenshin.md](../../../../kb/glossary/tokutei-kenshin.md)

## 6. この事実が支える論点

### 強調表示 【事実】

原典にフォント指定の太字はない。

### 逆引き 【解釈】

| 論点 | このスライドの使われ方 |
|---|---|
| 医療費適正化 | 予防による医療費の抑制。ただし本文に効果額の記載はない |
| 高齢者負担の在り方 | 注126の考慮要素「健康寿命の延伸」に対応 |
| 「高齢者」の定義見直し | 健康な高齢者が増えれば年齢区分の前提が変わる、という筋 |

## 7. 数字の読み方の注意

### ★★列挙だけで、数値目標も期限もない 【事実】

この2段落には、**達成すべき数値も、期限も、責任主体も書かれていない。**
「推進する」「図る」「取り組む」で終わる項目が並ぶ。

[p005](p005.md)（窓口負担：令和8年末までに一定の結論）や
[p006](p006.md)（2027年度薬価改定）と比べると、**拘束力の差は大きい**【解釈】。

【解釈】列挙型の記述は、各項目の所管部局が予算要求の根拠として引用できるようにする
形式と考えられる【推測】。医療保険部会の審議事項を直接規定するものではない。

### ★「健康寿命の延伸」が負担見直しの論拠になりうる 【解釈】

注126（→ [p005](p005.md)）は、窓口負担の見直しにあたり
「高齢者の就業率の上昇や**健康寿命の延伸**」を踏まえるとしている。

【解釈】この論法は
「健康寿命が延びている → 高齢者は以前より健康 → 年齢による負担軽減の根拠が薄れる」
という筋になる。

ただし[参考資料 p008](../sanko/p008.md)の分析にあるとおり、
**健康寿命は主観的健康観（国民生活基礎調査の自己申告）に基づく指標**であり、
平均寿命との差（不健康期間）が縮んでいるかどうかは
指標の取り方に依存する。数値をこの論点に使うときは定義の確認が要る。

### 「予防で医療費が下がる」とは書かれていない 【事実】

本文の目的語は「**Well-beingの向上と健康寿命の延伸**」「誰もが社会の担い手として
活躍できる日本」であって、**医療費の抑制ではない。**

【解釈】予防の医療費抑制効果については評価が分かれており、
骨太の本文が効果額に踏み込んでいないのは、その状況と整合する【推測】。
この資料には予防の費用対効果を示すスライドは含まれていない。

### 「国民皆歯科健診」に「いわゆる」が付いている 【事実】

> **いわゆる**国民皆歯科健診の具体化（歯周病検診の対象拡大や就労世代の歯科健診の更なる充実）

【解釈】括弧内が示すのは**既存の健診の対象拡大と充実**であって、
全国民を対象とする新たな健診制度の創設ではない。
「いわゆる」は、通称と中身がずれていることの断りと読める【解釈】。

### 保険者に関わる項目が2つある 【事実】

- 企業と保険者の**コラボヘルス**
- **PHR**の利活用と情報連携

【解釈】この2つは保険者の事業であり、保険者の実施体制・費用負担に関わる。
[参考資料 p018](../sanko/p018.md)（医療保険者における予防・健康づくりの重要性）と
突き合わせて読むべき箇所である。
