# 独立した照合の記録

SPEC §4-b は「別セッションで、解説とページ画像だけを渡して事実誤認を検証する」ことを求めている。
ここには、その趣旨で行った照合を、**誰が・いつ・何を・どうやって**確かめたかとともに記録する。

★この記録は `number_verified` を書き換える根拠にはならない。
`number_verified: true` は SPEC §6 の品質ルール3のとおり**人が原典と照合したとき**にだけ立てる。
ここに載っている照合はAIのセッションによるもので、人による照合ではない。
